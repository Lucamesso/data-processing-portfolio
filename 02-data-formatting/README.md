# Data Formatting

## Project Overview
This project focuses on standardizing an inconsistent synthetic e-commerce orders dataset.

## Objectives
- Standardize text fields.
- Convert dates into a consistent format.
- Normalize currency values.
- Convert numeric fields into appropriate data types.
- Ensure consistency across the dataset.

## Data Formatting Process
- Removed unnecessary spaces and standardized text capitalization.
- Standardized order IDs, customer names, countries and product names.
- Converted dates into ISO format (YYYY-MM-DD).
- Converted quantity values into integers.
- Standardized currency labels to EUR.
- Converted prices into numeric values.

## Key Results
- Standardized 40 records across 8 columns.
- All dates were converted into a consistent format.
- All prices were converted into numeric values.
- Quantity values were converted into integers.
- Text fields and currency labels were standardized.
- No missing values remained after formatting.

## Final Output
The formatted dataset was exported in CSV format.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Notes
The dataset is synthetic and was created for portfolio demonstration purposes.
